# CRM АУ — кабинет для Ильи Силивеева и помощников

CRM встроена в сайт и открывается по адресу `/crm/`. Код и данные свои, пока всё работает на этом компьютере. Устроена по двум образцам:
- реестр процедур и сроки отчётности — по образцу личного кабинета ААУ «СИРИУС» (см. «Опись ЛК Сириуса.md»);
- ведение самой процедуры — по образцу Rafinad.ai (см. «Опись Rafinad.ai.md»).

## Карточка процедуры

| Вкладка | Что там |
|---|---|
| Основное | Должник, суд, адрес суда, дело, даты, заявитель, отчётность, место составления и префикс исходящих номеров |
| Должник и семья | Паспорт, адреса, пол (для текстов документов), прожиточный минимум и расходы. Супруги, дети, источники дохода. Расчёт платёжеспособности за 36 месяцев |
| РТК | Реестр по очередям: залоговые, незалоговые, мораторные проценты, санкции, требования за реестром. Мораторные проценты считаются по дням. Изменения требований: правопреемство, исключение, перевод за реестр, смена очерёдности, залог. Отметка о праве голоса. Скачивание РТК в Word |
| Деньги | Счета с текущим остатком, текущие расходы по очередям п. 2 ст. 134, поступления и платежи. Платёж привязывается к расходам и требованиям, есть пропорциональное распределение по очереди. Сводка по очередям |
| Имущество | Объекты с полями по виду имущества, залог, исключение из массы, продажа. Дебиторка, меры по сохранности. Опись в Word |
| Люди | Контрагенты (их адреса подставляются в уведомления), привлечённые лица, работники (вставка из Excel), жалобы |
| Документы | «Создать документы»: отмечаете адресатов, CRM готовит черновики по шаблонам. Это запросы в госорганы, уведомления кредиторам и банкам, ходатайства в суд, тексты для ЕФРСБ и «Коммерсантъ». Текст можно править и скачать в Word. Учитываются отправка, трек и ответ. Почтовый реестр |
| Собрания | Мастер: параметры → повестка → участники и регистрация → голосование → документы. Участники берутся из РТК (голоса по ст. 12) или из списка работников. Кворум и итоги по ст. 15 считаются сами. В Word: уведомления, бюллетени, журнал регистрации, протокол, сообщения ЕФРСБ |
| Отчёт и финанализ | Отчёт АУ, отчёт об использовании денег, финанализ, заключения о признаках банкротства и об оспаривании сделок. Всё собирается из данных карточки и скачивается в Word |
| Суд и публикации | Заседания, споры, публикации. У спора есть № дела (по умолчанию банкротное дело, можно выбрать или вписать другой), комментарий и свои задачи: они видны на вкладке «Задачи» и в «Сроках» с названием спора |
| Отчёты в СРО | Журнал отчётов и собраний для Сириуса, как раньше |
| Задачи | Свои задачи и кнопка «Типовые задачи по процедуре»: сроки считаются от дат введения и назначения |

Перед первым документом заполните **Настройки → Мои реквизиты для документов**. Там же можно задать **адресатов запросов** и завести **свои шаблоны** с подстановками вида `{{должник}}`.

Шаблоны и сроки — рабочие черновики. Где в тексте стоит «[ ]», текст нужно дописать. Сроки с пометкой «по умолчанию» проверьте по закону и делу. Документы формируются прямо в браузере и в интернет не отправляются.

## Как запустить

Дважды щёлкните ярлык **CRM АУ** на рабочем столе. Можно и файл `siliveev-site\Сайт и CRM.cmd`.

- Запустится сервер сайта и CRM: свёрнутое окно «Site and CRM server». Пока сайт и CRM нужны, его не закрывайте.
- Откроется `http://127.0.0.1:5173/crm/`. Сам сайт — `http://127.0.0.1:5173/`, в его подвале есть ссылка «Вход для сотрудников».
- Сервер принимает подключения только с этого компьютера.

## Первый вход (один раз)

1. Откройте CRM. Появится экран «Первый запуск»: введите имя, логин (удобно — почту) и пароль. Пароль — не короче 10 символов, буквы и цифры.
2. Установите на телефон **Яндекс Ключ** или **Google Authenticator**, отсканируйте QR-код и введите шестизначный код.
3. Дальше вход всегда в два шага: пароль, затем код из приложения.

Первую учётную запись можно создать только на компьютере, где запущена CRM.

## Помощники

- Раздел **Помощники** → «Добавить помощника»: имя и логин. CRM выдаст временный пароль. Передайте его вместе с адресом и логином.
- При первом входе помощник подключает код в приложении и меняет временный пароль на свой.
- Назначить процедуры можно двумя способами:
  - в окне помощника — «Назначить процедуры», с поиском и отметкой галочками;
  - в карточке процедуры — блок «Помощники по процедуре».
- **Помощник видит только назначенные ему процедуры.** В них он может:
  - вести отчёты, требования, заседания, задачи и заметки;
  - менять поля карточки;
  - **удалять** закреплённые за ним процедуры (с подтверждением; восстановить может только владелец из архивной копии);
  - **подключать к ним других помощников** и снимать их в блоке «Помощники по процедуре» на вкладке «Основное». Себя снять нельзя: это делает владелец.
- **Помощник может создавать процедуры.** Новая процедура сразу закрепляется за ним, остальные помощники её не видят, пока он их не подключит. Владелец видит все процедуры.
- **Помощник не может:**
  - видеть чужие процедуры и удалять их;
  - менять настройки, добавлять помощников и сбрасывать пароли;
  - смотреть журнал и историю процедур;
  - выгружать список в CSV.
- Все действия помощников (создание, удаление, подключение коллег) записываются в журнал с его именем.
- В окне помощника есть кнопки:
  - «Сбросить пароль» — выдаёт новый временный;
  - «Сбросить код входа» — например, если помощник сменил телефон;
  - «Отключить доступ» — сразу завершает все сеансы помощника.

## Журнал действий

- В разделе **Журнал** записаны все входы, неудачные попытки входа и правки.
- Для правок видно, кто изменил, когда и что именно: «было → стало».
- По каждой процедуре история видна на вкладке **История** в её карточке.
- Журнал лежит в файле `данные\журнал.jsonl`. Из интерфейса его изменить нельзя.

## Защита

- **Пароли** хранятся только в виде стойкого хеша (scrypt).
- **Вход** — пароль плюс одноразовый код из приложения.
- **Блокировки:**
  - после 5 неверных паролей логин блокируется на 15 минут;
  - после 20 неудачных попыток с одного адреса блокируется адрес.
- **Сеанс** заканчивается через 4 часа бездействия, а в любом случае — через 12 часов.
- **Две правки одной карточки** не затирают друг друга. Если карточку только что изменил другой человек, CRM покажет свежую версию и попросит повторить правку.
- **Защита от поисковиков и чужих сайтов.** Раздел `/crm/` закрыт от поисковиков. Встроить его в чужую страницу нельзя. Изменяющие запросы с чужих сайтов отклоняются.

## Данные и копии

| Файл | Что это |
|---|---|
| `данные\crm.json` | процедуры и настройки |
| `данные\users.json` | учётные записи: хеши паролей и секреты кодов |
| `данные\журнал.jsonl` | журнал действий |
| `данные\архив\` | копии `crm.json` и `users.json`, по одной за день, последние 60 |

Папку `данные` не кладите в Obsidian, GitHub и облака: там персональные данные должников.

## Восстановление доступа

Если владелец потерял телефон с кодом или забыл пароль:

1. Закройте окно сервера.
2. В папке `siliveev-site` выполните одну из команд:

   Сбросить только код:

   ```
   node crm/tools/reset-access.mjs ВАШ_ЛОГИН
   ```

   Сбросить код и пароль (команда выдаст временный пароль):

   ```
   node crm/tools/reset-access.mjs ВАШ_ЛОГИН --password
   ```

3. Запустите CRM и войдите: она попросит подключить код заново.

Помощникам доступ сбрасывает владелец в разделе «Помощники».

## Загрузка из Сириуса

21.10.2026 из личного кабинета загружены 79 процедур и 47 записей об отчётах и собраниях.

Повторную загрузку делает Claude через встроенный браузер, пока вы вошли в кабинет Сириуса:
- новые процедуры добавляются;
- у уже загруженных обновляются данные из Сириуса;
- ваши записи и назначения помощников не затрагиваются.

## Когда понадобится доступ из интернета

Сейчас CRM доступна только с этого компьютера. Чтобы помощники работали из дома или из суда, нужен свой сервер (VPS) в России, а не обычный PHP-хостинг: CRM работает на Node.js.

На сервере запускается тот же `serve.mjs`, и он отдаёт и сайт, и CRM. Перед ним ставится nginx с HTTPS (бесплатный сертификат Let's Encrypt) и переменной `TRUST_PROXY=1`. Без HTTPS открывать CRM в интернет нельзя.

Владельца проще всего создать здесь, до переноса, и перенести вместе с данными (`users.json`). Экран «Первый запуск» из интернета не откроется. На самом сервере его можно открыть через SSH-туннель: тогда сервер считает вход локальным.

Кроме того, для доступа из интернета понадобятся:
- уведомление в Роскомнадзор об обработке персональных данных;
- обязательства помощников о неразглашении.
